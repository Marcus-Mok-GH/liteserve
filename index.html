Chat runs 100% in your browser — no API keys, no server, nothing leaves this device. Pick a model, hit Load model (first download is cached), then chat. After that it works even when everything else sleeps. The model runs in a background worker thread, so the page stays responsive while it thinks.
Needs WebGPU — Chrome/Edge on desktop, Chrome 121+ on Android. Check webgpureport.org if it won't load.
